# 2026-10-13: v1.0.2 (toolbar that keeps every tool in view)

Follows `2026-10-13-v1.0.1.md`.

## Problem

With button labels on, the style controls (eight swatches, a colour picker, and a 72 px
slider beside each number field) took about 1,000 px at a fixed width. The tools got
the rest, inside a strip that scrolled with a hidden scrollbar. Measured: at 1440 px
60% of the tools were hidden (including the active text-box tool), at 1100 px nearly
all of them; icons-only mode clipped at 1280 px with the text tool. The page counter
wrapped ("/" above "4") and selected buttons had grey labels on blue.

## Changes (`Toolbar.svelte`)

- **`ColourWell.svelte`**: one button showing the colour; opens a palette with the
  presets and a custom picker.
- **`SizeField.svelte`**: an icon plus `NumberInput`; the icon opens the slider in a
  popover. Used for stroke width, font size, mark size and opacity.
- **Layout:** the tools, Stamp/Signature and Apply Redactions sit in `.tools-main`. The
  `.row.tools` wraps, so `.style` moves to its own line (class `wrapped`, set by a
  `ResizeObserver`) instead of squeezing the tools.
- **Label mode:** the top row and the tool groups wrap by group; `.tool-group` becomes
  `display: contents` so Stamp/Signature flow with the rest; dividers are replaced by
  a 12 px gap.
- **Fallback:** the `scrollFade` attachment fades the hidden edge of any strip that
  still scrolls (icons-only on very narrow windows) and maps the vertical wheel to
  horizontal scrolling.
- **Smaller fixes:** `.pages` no-wrap; selected labels inherit the button's text colour;
  alignment icons instead of L/C/R; GNOME/Linux buttons get `height: auto` in label
  mode.
- **New toolbar buttons:** Straighten (opens `StraightenDialog`) and Perspective (toggles
  `session.startPerspective` / `cancelPerspective`), beside OCR.

## Tests

`verify:ui` 146/146. New checks: every toolbar button fully on screen with labels at
1100 px, palette sets the colour, size icon opens the slider, and both new toolbar
buttons work. The screenshot script picks colours through the palette.
