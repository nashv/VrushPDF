# 2026-10-10: v0.5.12 (OCR, no auto-select, text layer fixes)

Follows `2026-10-10-v0.5.11.md`; that log's "Before you continue on the other computer"
section still applies.

## OCR (Tesseract.js, offline)

- **Make searchable:** File ▸ Recognise Text (OCR)…, the OCR toolbar button, or the
  command palette. `OcrDialog.svelte` → `session.makeSearchable`. It OCRs the chosen
  pages (skipping pages that already have text by default), builds the PDF from the
  current edits, adds an invisible text layer, and reopens the result through the same
  `#reloadTransformed` path that applying redactions now shares. Undo history starts
  over. The busy indicator has a Cancel button (`session.cancelBusy`).
- **Text layer:** `annotations/ocrText.ts`. Each word is drawn in render mode 3
  (invisible) with a full text matrix, stretched to the scanned width and turned to the
  scan's direction. Plain Helvetica/WinAnsi covers the six bundled languages; characters
  it can't encode become `?`. The page's existing content is wrapped in q/Q first.
- **Engine:** `ocr/engine.ts`. It renders at 300 DPI using the page rotation the user
  sees (capped at 5000 px), runs Tesseract in a single queued worker, and frees the
  worker after 60 s idle. Orientation: if a read isn't mostly confident, horizontal,
  multi-letter words, it tries the other three quarter-turns and keeps the best. (Page
  layout mode turns vertical lines internally and reports tall word boxes, so those
  don't count as upright.)
- **Region tool:** the `ocr` tool. Drag a box; the text goes to the clipboard through a
  `ClipboardItem` with a pending promise, claimed during the pointer event because
  recognition outlasts the user-activation window. `OcrResult.svelte` shows the text with
  an editable box and a Copy button. It's a read-only tool, so it still works after the
  trial ends.
- **Assets:** `scripts/copy-ocr-assets.mjs` runs from `prepare`, so `npm install`/`npm ci`
  (CI included) copy the worker, three LSTM engine builds and six `best_int` language
  models into `static/ocr/`, which is git-ignored (~25 MB). Languages: eng, deu, fra,
  spa, ita, nld. The list is duplicated in the script and in `OCR_LANGUAGES`; keep them
  in step.

## Newly added annotations stay unselected

`EditStore.add` no longer selects, and the post-creation `edits.select(...)` calls in
`PageView` are gone, so the user can add annotations one after another. Only clicking,
double-clicking, the context menu on an existing annotation, or Tab between text boxes
select. Keep it that way for new tools.

## Pre-existing bugs fixed along the way

1. **Text layer offset on 90°/270° pages.** pdf.js sizes `.textLayer` with
   `var(--scale-round-x/y)`, which it defines only under `.pdfViewer .page`. With them
   undefined the size was invalid and every selectable word sat about 140 px off on
   rotated pages. Defined in `app.css`.
2. **Text layer drawn twice.** A mount superseded mid-render left its spans in the shared
   container, so text was selected and copied twice. `mountTextLayer` now renders into its
   own `.textLayer` element inside PageView's `.text-host` and removes it on
   cancel/failure.
3. **verify:roundtrip reported async checks before they ran.** `check()` now waits for
   promises. The redaction test had never really run, and it read text from compressed
   bytes; it now reads through pdf.js and genuinely passes.
